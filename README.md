# 칭찬스티커 (건) 🎯

5가지 색깔 원 스티커(빨, 노, 파, 초, 보)로 칭찬을 기록하고 모으는 반응형 웹앱입니다.

## 주요 기능
- **5가지 색상 원 스티커**: 빨강, 노랑, 파랑, 초록, 보라 원 스티커 지원
- **실시간 칭찬판 그리드**: 스티커 붙이기, 메모 남기기, 스티커 조회/수정/삭제
- **RGB & HEX 테마 색상 팔레트**: 16진수(#HEX) 및 R,G,B 직접 숫자 입력(0~255) 및 실시간 미리보기 동기화
- **다중 보드 관리**: 사이드바를 통한 보드 추가 및 전환, PIN 비밀번호 보호
- **로컬 스토리지 & Supabase 클라우드 동기화 지원**
